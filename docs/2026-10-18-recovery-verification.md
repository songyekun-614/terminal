# 异常关闭恢复

按用户选择，下次启动先显示恢复提示，由用户选择“恢复会话”或“新建终端”。恢复标签页顺序与名称、分屏结构与比例、活动标签和面板、Shell 及工作目录。每个面板启动新的 Shell；不恢复原进程、屏幕历史、未提交输入和临时环境变量，也不会自动重跑命令。

正常关闭不触发恢复。提示未处理时关闭窗口会保留记录，Escape 不会丢弃记录；只有明确选择“新建终端”才放弃该次恢复。多个异常窗口按最近保存时间依次提供恢复。目录或 Shell 已不可用时退回主目录或默认 Shell。

## 存储与失败处理

- 工作区变化防抖 200ms，并每 1.5 秒检查目录变化；完全相同的数据不重复落盘。异常结束前约两秒内的变化可能尚未保存。
- 快照位于应用配置目录的 `recovery` 子目录，目录权限 0700，文件权限 0600。只保存经过验证的结构、名称、目录和 Shell 元数据。
- 每个窗口独立记录。进程身份用于区分 PID 重用；无法确定身份时保守保留仍存活进程的记录。原子重命名认领记录，避免两个新窗口同时恢复同一份工作区。
- 临时文件写入、文件同步及重命名完成后才更新内存状态。重命名是提交边界；后续目录同步失败仅报告警告，避免磁盘和内存对恢复状态判断不一致。
- 恢复失败清理部分新建会话，保留原记录并允许重试。损坏、超限或不合法的记录不会阻止正常启动。

## 界面

沿用此前 Apple Design Skill 指导下的原生对话框、系统字体、颜色、分组摘要和键盘焦点行为。深浅主题截图：[深色](images/recovery-dark.png)、[浅色](images/recovery-light.png)。

同时修正了快捷键设置关闭后的同步焦点恢复：保存或取消立即返回终端，避免紧接着按 Escape 时事件落到入口按钮。
