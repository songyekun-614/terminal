# 自定义快捷键

当前 Electron 版本新增 19 个可配置操作，涵盖标签页、分屏、编辑与搜索、字号和设置。入口为“更多操作 → 快捷键设置…”以及外观设置中的同名按钮。点击按键录入；支持清除、冲突提示、恢复默认、取消和保存，保存立即生效并写入现有 settings.json。

## 行为

- 配置解析、规范化、保留键检查和事件匹配由 `desktop/src/shortcuts.cjs` 统一提供，主进程与渲染器共用同一份规则。
- 默认绑定延续已有行为；自定义绑定会替换旧绑定。Ctrl+C 的选区复制/中断及 Ctrl+V 粘贴别名保留。
- 普通字符需要 Ctrl、Alt 或 Meta，功能键支持 F1–F24。常见系统保留组合拒绝保存；系统实际拦截的组合可能不会送达应用。
- 重复组合及默认放大字号的等价组合会提示冲突并阻止保存，允许清除原绑定后交换。
- 录入期间不执行终端命令，Esc 取消录入，Tab / Shift+Tab 结束录入并导航，Ctrl+Tab 等修饰组合可录入，Delete / Backspace 清除。
- 清除“关闭面板或退出”后，单独 Esc 会送入真实 PTY；弹窗、菜单与搜索中的 Esc 取消始终保留。组合键严格匹配，忽略 IME composition、229 与 AltGraph。
- 工具栏及面板/标签关闭按钮的 title、aria-keyshortcuts 随配置更新。读屏描述同时报告当前组合键、录入状态及错误。
- 快捷键通过独立 IPC 保存，不保存外观草稿，也不清理正在预览的壁纸；取消外观设置不会撤销已保存的快捷键。保存失败保留草稿和错误，支持重试。

## Apple 设计依据

使用 [Apple Design Skill](https://github.com/dickwu/apple-design-skill)，读取基础布局、无障碍、字体、颜色、桌面设计、设置、键盘、焦点、列表和按钮指导，按 Electron/Windows/Linux 语境应用。

- `settings.md › General settings`：将键盘映射放在设置中，沿用已有终端的系统字体与配色。
- `layout.md › Visual hierarchy`：用分组标题、对齐列表和轻分隔线表达操作类别；按键帽是本界面的主要视觉特征。
- `keyboards.md › Best practices`：尊重标准快捷键，并提供纯键盘录入与导航。
- `focus-and-selection.md › Best practices`：录入时有明确焦点，退出设置后返回终端；从外观设置进入时返回原控件。

面板采用原有 18px 圆角，分组 12px 圆角，行高至少 48px，按键录入区域至少 32px，清除按钮 28px。沿用 13px 系统字体与 12px 辅助文字；标题与操作按钮不添加无关装饰或内容模糊效果。现有减少动画及高对比规则保留。

深色辅助文字 `#a3a7b1` / `#24262b` 对比度 6.29:1；浅色设置范围内辅助文字 `#686b73` / `#eeedeb` 为 4.56:1。错误文字深/浅分别为 8.32:1、5.89:1；焦点框深/浅分别为 7.38:1、4.47:1。

真实截图：[深色](images/shortcuts-dark.png) · [浅色](images/shortcuts-light.png)。640×560 窗口检查无横向溢出，列表独立滚动，保存/取消区域始终可见。
