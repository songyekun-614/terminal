Windows / Linux 独立终端，本版新增自定义快捷键与异常关闭恢复。

- 在“更多操作 → 快捷键设置…”或外观设置中配置 19 个操作，支持录入、清除、冲突提示、恢复默认、取消和保存，保存后立即生效并持久保留。
- 清除“关闭面板或退出”的 Esc 绑定后，可将 Esc 传给 Vim 等终端程序；Ctrl+C 选区复制/中断与 Ctrl+V 粘贴别名保留。
- 异常退出后，下次启动先提示恢复；恢复标签页名称与顺序、嵌套分屏及比例、活动面板、Shell 和工作目录。
- 正常退出不触发恢复；未选择时关闭提示窗口仍保留记录，只有明确选择“新建终端”才放弃本次恢复。多个异常窗口依次提供最近的记录。
- 恢复会启动新的 Shell，不续跑原进程、不自动重跑命令，也不恢复屏幕历史、未提交输入和临时环境变量。最后约两秒的变化可能尚未保存。
- 目录或 Shell 不可用时自动回退；损坏记录不阻止启动；恢复失败保留原记录并可重试。
- 修复快捷键设置关闭后立即按 Esc 的焦点竞态，保留已有分屏、外观、代理与壁纸设置。

发布前在 Windows / Linux 的 x64、ARM64 四个原生环境执行服务测试、界面测试、安装包构建与打包后回归，全部通过才正式发布。IBus 中文输入专项需要额外桌面环境，不属于本次 CI 验证范围。

下载与系统架构一致的文件：Windows 使用 setup.exe 或 zip；Debian / Ubuntu 使用 deb；Fedora / openSUSE 使用 rpm；其他 Linux 桌面可使用 AppImage。10 个安装包配有 SHA256SUMS 校验文件。

安装步骤见仓库 README。安装包无需 Node.js 或 Python。Windows 安装包未签名；macOS 暂无安装包。安装、升级和卸载生命周期及未覆盖的发行版仍需实机验证。
