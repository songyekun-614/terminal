Windows / Linux 独立终端，重新发布 0.3.0，修复 Esc 与 CLI 的按键冲突。

- Esc 在终端内直接传给 Shell 或前台 CLI，不再关闭面板、标签页或窗口；弹窗、菜单和搜索仍可用 Esc 取消。
- 关闭当前面板使用 Ctrl+Shift+X，关闭标签页使用 Ctrl+Shift+W。
- 保留已有 B 版分屏：12px 圆角、2px 接缝、12px 拖动区域，以及分屏拖动、键盘调节和独立 Shell。
- 保留关闭标签页及窗口的确认提示、中文输入修正、外观、壁纸、代理和剪贴板行为。
- 此版本不包含 0.4.0 的自定义快捷键和异常退出恢复；分屏布局暂不跨启动保存。

发布前在 Windows / Linux 的 x64、ARM64 四个平台运行服务测试、真实 PTY / ConPTY 界面测试、安装包构建和打包后回归，全部通过后替换安装包，并核对上传文件的 SHA256 digest。

提供 Linux x64 / ARM64 各 AppImage、deb、rpm，Windows x64 / ARM64 各 setup.exe、zip，共 10 个安装包与 SHA256SUMS。请重新下载并使用本次发布的校验文件。

Windows 安装包未签名；macOS 暂无安装包。0.4.0 仍为最新版本，本次更新面向使用 0.3.0 的用户。
