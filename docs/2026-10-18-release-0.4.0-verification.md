## 发布过程中处理的问题

首次 Windows 强制结束恢复测试结束的是 Playwright 创建的 cmd.exe 包装进程，实际 Electron 仍存活，因此恢复服务正确忽略了该活动窗口的记录。测试改为对实际 Electron 主进程执行 taskkill /T /F，并核实进程退出。产品代码未因该问题修改；修正后两个 Windows 架构的恢复测试全部通过。

Windows x64 首轮打包回归在已有的 15 标签页测试结束清理时超时；相同的清理超时曾在 0.3.0 发布验证中出现。保持同一源码提交单独重跑 Windows x64 后，两轮完整界面测试均通过，三个已通过的平台结果保留。该次偶发超时被记录，不据此声称彻底消除了 ConPTY 清理的偶发超时。

正式 Release 提供 Linux x64 / ARM64 各 AppImage、deb、rpm，Windows x64 / ARM64 各 setup.exe、zip，共 10 个安装包与 SHA256SUMS。发布任务检查所有安装包存在、生成并逐项验证 SHA256SUMS，全部上传后公开 Release。

发布标签、目标提交、11 个附件的名称、上传状态及非零大小均已核对。额外读取公开 SHA256SUMS，与 GitHub 附件的 SHA256 digest 逐项核对一致。
